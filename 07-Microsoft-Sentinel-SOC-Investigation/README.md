# Microsoft Sentinel SOC Investigation



## Project Goal

Build a hands-on SOC investigation using Microsoft Sentinel and KQL.

## Planned Work

- Learn KQL fundamentals
- Configure Microsoft Sentinel
- Analyse security logs
- Create KQL investigation queries
- Investigate a security alert
- Analyse a Sentinel incident
- Identify indicators of compromise (IOCs)
- Map activity to MITRE ATT&CK
- Document investigation findings
- Produce a SOC incident report
